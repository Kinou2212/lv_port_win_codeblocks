# pc_simulator_win_CLion
PC simulator project for LittlevGL embedded GUI Library for Windows in CLion or just CMAKE.

## How to use this:

###  Tutorial for Windows
1) Download and install [Git](https://git-scm.com/downloads) 
2) Download CLion or just CMAKE and MINGW64. 
3) Clone this repository and select branch, typing: 
```
git clone -b to_clion https://github.com/Kinou2212/lv_port_win_codeblocks.git
```
4) Build it.
   - For Clion, open folder as CLion Project and enjoy it.
   - For CMAKE, type in terminal:
   ```angular2html
   cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug
   cmake --build build
   ```
